
# MICAN SCHOOLS CONNECT

**By MICAN Technologies**

**Tagline:** One Network. Many Schools. One Connected Future.

## 1. Our Vision

MICAN SCHOOLS CONNECT is a global education platform designed to connect schools, teachers and students through one professional digital network.

We will launch in Nigeria before expanding internationally.

## 2. Main Features

1. School Network — school registration, profiles and connections.
2. Global Arena — inter-school academic competitions.
3. Student Portfolio — projects, skills and achievements.
4. Teacher Connect — teacher collaboration.
5. Learning Resources — approved educational materials.

## 3. Account Types

- Platform Administrator
- School Administrator
- Teacher
- Student

Each account will have clearly defined permissions.

## 4. Business Model

- Free school registration.
- Free basic features.
- Optional premium features.
- Transparent pricing for schools.

## 5. Technology Direction

- Website: Next.js and TypeScript.
- Mobile app: React Native and Expo.
- Backend: Supabase.
- Database: PostgreSQL.
- Hosting: Vercel.

The website and mobile app will use the same secure backend.

## 6. Security

- Each school must have private, protected records.
- Schools must not access another school's private information.
- Only authorized administrators can approve schools.
- Teachers and students receive permissions appropriate to their roles.
- Private credentials must never be exposed in public application code.

## 7. Development Stages

1. Project foundation.
2. Database and authentication.
3. School registration and approval.
4. School dashboards.
5. School Network.
6. Teacher Connect.
7. Student Portfolio.
8. Global Arena.
9. Mobile application.

Every stage will be tested before moving to the next.
